# pkgwise

Intelligent insights for the software package ecosystem.

## Tech Stack

- [Nuxt 4](https://nuxt.com) — Vue 3, TypeScript, SSR
- [Nuxt UI](https://ui.nuxt.com) — component library
- [Tailwind CSS 4](https://tailwindcss.com) — styling
- [reka-ui](https://reka-ui.com) — headless primitives for custom components
- [VueUse](https://vueuse.org) — composable utilities

## Setup

Install the dependencies:

```bash
pnpm install
```

## Development

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Scripts

| Command | Purpose |
| --- | --- |
| `pnpm dev` | Start dev server |
| `pnpm lint` | Lint the project |
| `pnpm lint:fix` | Lint and auto-fix |
| `pnpm typecheck` | Type-check with vue-tsc |
| `pnpm build` | Production build |
| `pnpm preview` | Preview production build |
